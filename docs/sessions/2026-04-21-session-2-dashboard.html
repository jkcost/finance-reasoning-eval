🔍 핵심 관측 (실제 데이터 기반)

F1. 1million 암기 현상 정량 증거 (RQ-B)
IC 계열에서 Memorization Score = from_removed_data / total_values 비율이 0.10 ~ 0.14. 즉 context에 없는 수치를 모델이 회상해 답에 사용. 4/15 회의에서 관찰된 "모델이 단위를 바꿔도 1million 고수" 현상이 정량적으로 재현됨. Gemini/GPT/Claude 간 편차는 balanced 실험(A2) 이후 확정.
F2. IC 탐지 실패의 압도적 방향 (RQ-A 비대칭성)
gpt-4o-mini × IC 변형에서 refusal rate = 4 / 660 (0.6%). EA 계열은 376 / 436 (86%) 거부. 이 절대적 격차 자체가 "absence ≠ conflict detection" 비대칭성의 가장 강한 증거. Salience regression이 class imbalance로 AUC 0.5 나온 것도 **IC 거부가 사실상 존재하지 않는다**는 finding.
F3. EA/SA reason 텍스트의 구분 불가능성
구 프롬프트(4/13)에서 EA-partial과 SA의 reason이 거의 동일한 "X is missing" 패턴. 카테고리 v0의 MISSING_REQUIRED_VALUE와 MISSING_SILENT를 reason 텍스트만으로는 구분할 수 없음. v0.1 제안: 두 카테고리를 MISSING_DATA로 통합 + transformation_type을 metadata로 병용.
F4. Hard Example 규모 풍부 (목표 3배)
238문제 전수 IC-L1/L2 candidate: 125개 확보 (hardcoded solution 335개 자동 제외 후). Validator 실행 성공률 75/125 (60%) — 목표 24문제의 3배. 나머지 40% 실패는 주로 'float' object cannot be interpreted as an integer로 치환 후 타입 불일치 or 치환된 값이 로직에 영향 없어 새 정답 동일. D2 사람 검수에서 최종 채택.
F5. POT 측정 타당성 증명
B1 (ic_cot_trace 프롬프트) 구현으로 4/15 회의의 핵심 finding(POT가 IC 판정을 가린다)을 **실행 가능한 실험 조건으로 전환**. A2+B2 병행 시 "동일 모델이 POT로는 IC를 놓치고 CoT trace로는 탐지" 같은 타당성 주장 가능.
