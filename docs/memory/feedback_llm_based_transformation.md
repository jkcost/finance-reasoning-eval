---
name: 변환은 반드시 LLM 기반으로 수행
description: 문제 변환(EA/SA/IC/TA)은 규칙 기반이 아닌 LLM 기반으로 해야 한다는 핵심 원칙
type: feedback
---

문제 변환은 반드시 LLM 기반으로 수행해야 한다. 규칙 기반(regex, 키워드 매칭) 변환을 사용하면 안 된다.

**Why:** 규칙 기반 변환은 금융 맥락을 이해하지 못해 (1) 풀이와 무관한 데이터를 제거하거나, (2) 역산 가능한 데이터를 제거하여 여전히 풀 수 있는 문제를 만드는 등 부적절한 변환을 생성함. 사용자가 LLM 기반 변환을 기대했는데 규칙 기반으로 구현되어 있어 혼란이 발생함.

**How to apply:**
- `apply_transformations_full.py`의 기존 규칙 기반 함수는 v1 레거시로 취급
- 새 변환 파이프라인은 LLM에게 문제 + python_solution + 변환 기준을 전달하여 변환 생성
- LLM이 판단해야 할 것: (1) 필수 데이터 식별, (2) 역산 가능성 체크, (3) 자연스러운 변환 생성
- Human Review는 LLM 변환 결과에 대해 수행
