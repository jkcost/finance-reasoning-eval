## Decisions (핵심 결정)

1. **연구 앵글 확장**: 현재 단순 perturbation은 binary classification에 머물러 재미 부족 → 두 가지 앵글 추가
   - **A1. 판정 이유(judgment reason) 카테고리화**: 거부 시 모델이 남긴 이유를 4~6개 카테고리로 클러스터링 → 모델이 *왜* 못 푸는지 맞추는지 평가 (메타인지 Part 2)
   - **A2. Hard example 생성**: IC-L1/L2(숫자·단위 변형)처럼 변형 후에도 정답 재계산 가능한 유형은 Python solution으로 새 정답 만들어 hard example accuracy 실험 (HLE 스타일, 전체의 ~1/10 규모)
2. **POT 프롬프트 한계 발견 → CoT/reasoning trace로 전환**: IC-L2/L3/L4는 "어느 값을 왜 선택했는지"를 봐야 판정 가능한데 POT는 코드만 내므로 추적 불가. 후속 실험부터 명시적 reasoning trace 프롬프트 사용. **POT 한계 자체를 CIKM Short finding으로 포함**.
3. **1million 암기 현상 재현 → RQ-B 직접 증거**: EA-partial로 원금을 지워도 모델이 1million을 스스로 회상. 모델별 편차 — Gemini는 단위 바꿔도 1million 고수(강한 편향), GPT-4o-mini는 단위 따라 10K/100K로 바뀜, Claude는 혼재. 실험 설계 문제가 아니라 학습 데이터 편향.
4. **실험 스코프 축소 옵션**: 원본 컨텍스트에서도 오답인 문제는 분석에서 제외해도 무방 (교수 의견). "원본 맞춤 → 변환 후 어려워짐" 경로에 집중.
5. **난이도 레벨 세분화 여지**: EA-partial 내부에서도 1개/3개/5개 삭제 등 세밀한 난이도 설정 가능 (현재는 단일 레벨).
6. **IC L3(권위 충돌) 기대 응답 재정의**: 모델이 "두 값이 있어 불확실" 응답을 내야 정상이나, 실제로는 권위 marker 따라 한 값 찍음. POT는 이 판정을 측정 못 함 → A1의 reason 실험으로 가능.
7. **타임라인 유지**: 5월 CIKM Short(현재 발견 + 한계 논의) → 8월 AAAI(agentic 해결 방법).
