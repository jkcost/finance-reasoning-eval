# Human Review 가이드

## 개요

이 리뷰의 목적은 **LLM 메타인지 평가를 위한 고품질 변환 데이터셋**을 만드는 것입니다.

원본 금융 문제(hard.json, 120문제)에서 풀이에 필요한 데이터를 자동으로 제거/변형하여
"unsolvable" 문제를 만들었습니다. 이 자동 변환이 올바른지 사람이 검토합니다.

## 변환 유형 (8가지)

HTML 상단의 **"변환 유형 가이드 & 리뷰 기준"**을 펼치면 각 타입의 상세 설명을 볼 수 있습니다.

### Absence (정보 부재) — 3가지

| 타입 | 방법 | 리뷰 포인트 |
|------|------|-------------|
| **EA-partial** | 값을 `N/A`로 교체 | N/A로 바뀐 값이 풀이에 실제로 필요한가? |
| **EA-full** | 칼럼/키 전체 삭제 | Python Solution 초록 변수에 해당하는 칼럼이 **정말 삭제됐는지** 확인 |
| **SA** | 마커 없이 조용히 삭제 | 삭제 후 문맥이 자연스러운지, 삭제된 정보 없이 정말 풀 수 없는지 |

### Conflict (정보 충돌) — IC L1~L4

| 타입 | 방법 | 리뷰 포인트 |
|------|------|-------------|
| **IC-L1** | 숫자를 10배 틀리게 | 10배 오류가 문맥상 눈에 띄는지, 풀이에 사용되는 값인지 |
| **IC-L2** | 같은 값을 다른 단위(million/billion)로 삽입 + 1.5x 오류 | 단위 변환이 **실제로 틀린지** 확인 (올바른 변환이면 충돌 아님!) |
| **IC-L3** | 권위 출처가 1.5x 모순값 제시 | 모순이 자연스럽게 삽입됐는지, 대상이 풀이에 사용되는 값인지 |
| **IC-L4** | 분기합 ≠ 연간총계 | 합산 불일치가 실제로 존재하는지, 숫자들이 같은 시리즈인지 |

### 보조 — 1가지

| 타입 | 방법 | 리뷰 포인트 |
|------|------|-------------|
| **TA** | 연도 → "해당 기간" | context에 여러 연도 데이터가 있어서 실제로 모호해지는지 |

## 판정 기준

| 판정 | 기준 | 예시 |
|------|------|------|
| **승인** | 제거된 정보가 풀이에 필수적이며, 남은 정보로는 답을 도출할 수 없음 | ROE 계산에 필요한 순이익을 삭제 → 풀 수 없음 |
| **수정 필요** | 방향은 맞지만 개선이 필요 | 풀이와 무관한 값을 삭제 / 너무 많이 삭제 |
| **부적절** | 변환 후에도 문제를 풀 수 있거나 변환이 의미 없음 | 삭제한 칼럼의 값을 남은 칼럼에서 읽을 수 있음 |

## EA-full 리뷰 방법 (상세)

EA-full은 칼럼 전체를 삭제하는 변환입니다. 가장 주의가 필요합니다.

### 확인 방법

1. 문제 하단의 **Python Solution**을 봅니다
2. **초록색(●) 변수**가 최종 답 계산에 사용되는 값입니다
3. 변환된 context에서 **초록 변수명과 일치하는 칼럼이 삭제됐는지** 확인합니다
4. 초록 변수에 해당하는 칼럼이 **아직 남아있으면** → **부적절** (모델이 그 값을 읽을 수 있음)

### 역산 가능 경고

⚠️ 주황색 "역산 가능 경고" 배너가 표시되는 경우:
- 시스템이 자동으로 탐지한 것으로, 삭제된 칼럼의 값이 남은 칼럼들의 관계식에서 계산될 수 있음을 의미합니다
- 경고가 있으면 **더 신중히 확인**해주세요
- 금융 지식이 없어도 됩니다 — 초록 변수와 칼럼명 매칭만 확인하면 됩니다

## 작업 흐름

```
[1] 브라우저에서 본인 담당 URL 열기
[2] 각 문제의 8개 탭 확인 → 판정 (승인/수정필요/부적절) + 메모
[3] 작업은 자동 저장됨 (브라우저 닫았다 열어도 이어서 가능)
[4] 완료 후 "내보내기" 클릭 → JSON 파일 다운로드
[5] JSON 파일을 관리자에게 전달
```

### 소요 시간

- 1문제당 약 5-10분 (8개 탭 × 30초~1분)
- 30문제 담당 시 약 2.5~5시간

---

## JSON 제출 후

관리자가 모든 작업자의 JSON을 모아서:

```bash
# 요약 대시보드 생성
python experiments/generate_review_summary.py
```

`review_summary.html`을 팀 전체와 공유하여:
- 각자의 리뷰 결과를 한눈에 확인
- **"토론 필요"** 섹션에서 수정필요/부적절로 판정된 건을 팀이 함께 논의
- 최종 결정 후, 승인된 변환만 모델 실험에 투입

## FAQ

**Q: 금융 전문 지식이 없어도 리뷰할 수 있나요?**
A: 네. 대부분의 리뷰는 "Python Solution의 변수명과 context의 칼럼명이 일치하는지" 확인하는 작업입니다. 금융 항등식 판단이 필요한 케이스는 시스템이 자동으로 경고를 표시합니다.

**Q: 브라우저를 닫으면 작업이 날아가나요?**
A: 아닙니다. localStorage에 자동 저장되므로 같은 URL로 다시 열면 이어서 할 수 있습니다.

**Q: 변환된 context를 직접 수정할 수 있나요?**
A: 네. 각 변환 탭에 편집 가능한 textarea가 있습니다. 수정하면 내보내기 시 수정된 내용이 포함됩니다.

**Q: IC-L2에서 단위 변환이 올바른 것 같은데요?**
A: IC-L2는 단위 변환에 1.5배 오류를 포함합니다. 예를 들어 $500 million이 0.75 billion으로 표현되면, 올바른 변환은 0.5 billion이어야 하므로 이건 충돌입니다. 변환이 올바르면(오류 없이 정확한 단위 변환이면) **부적절**로 판정해주세요.
