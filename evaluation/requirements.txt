# FinanceReasoning Evaluation System

FinanceReasoning arXiv paper 기반 LLM 평가 시스템

## 📋 완료된 컴포넌트

### 핵심 모듈

1. **config.py** - API 키 관리 (env vars + YAML 설정)
2. **dataset_loader.py** - FinanceReasoning 데이터셋 로드
3. **prompt_builder.py** - 구조화된 프롬프트 생성
4. **model_runner.py** - 비동기 LLM 실행, 레이트 리미팅, 비용 추적
5. **response_parser.py** - LLM 응답 및 추론 단계 파싱
6. **metrics_evaluator.py** - 6종 평가 지표 계산
7. **result_store.py** - SQLite 저장소 및 캐싱

### 지원되는 LLM 프로바이더

- **OpenAI**: GPT-5, GPT-4o, GPT-4o Mini
- **Anthropic**: Claude Sonnet 4.5, Claude Sonnet 4.1

## 📊 평가 지표 (Paper 기준)

### 1. Final Answer Accuracy
정답 정확도 (ground_truth과 LLM 응답 비교)

### 2. Step Completeness
추론 단계 완전성 (ground_truth_steps 중 몇 퍼센트 포함)

### 3. Step Order Correctness
추론 단계 순서 정확성

### 4. Reasoning Similarity
추론 유형 분포 유사성 (Jaccard Index, 0-1.0)

### 5. Hallucination Rate
할루시네이션 비율 (LLM이 ground_truth에 없는 단계 생성 비율)

### 6. Overall Reasoning Score
종합 점수 (Paper 공식):
```
Overall Reasoning Score =
  (Final Answer Accuracy × 0.4) +
  (Step Completeness × 0.3) +
  (Step Order Correctness × 0.1) +
  ((1 - Hallucination Rate) × 0.2)
```

## 🚀 시작 방법

### 1단계: 환경 설정

```bash
# 프로젝트 루트에서 .env 파일 생성

# OpenAI API 키
OPENAI_API_KEY=sk-...

# Anthropic API 키
ANTHROPIC_API_KEY=sk-ant-...
```

### 2단계: 평가 실행

```bash
# 평가 수행 (예: 5개 예제, hard.json 전체)
python -m financereasoning.eval run-eval \
  --dataset hard \
  --limit 5 \
  --models gpt-5-2025-08-07,claude-sonnet-4.5
```

### 3단계: 결과 조회

```bash
# 평가 결과 확인
python -m financereasoning.eval get-eval <eval_id>
```

### 4단계: 보고서 생성

```bash
# 보고서 생성 (Markdown 형식)
python -m financereasoning.eval report <eval_id>
```

## 📋 사용 예시

### 예제 1: 기본 평가

```bash
# 전체 데이터셋에서 5개 예제 평가
python -m financereasoning.eval run-eval \
  --dataset hard \
  --limit 5 \
  --models gpt-5-2025-08-07
```

### 예제 2: 특정 난이도만 평가

```bash
# hard 난이도만 평가
python -m financereasoning.eval run-eval \
  --dataset hard \
  --limit 10 \
  --level hard \
  --models claude-sonnet-4.5
```

### 예제 3: 비용 한도 테스트

```bash
# 최대 비용 $5.00으로 제한
python -m financereasoning.eval run-eval \
  --dataset hard \
  --limit 3 \
  --max-cost-usd 5.0 \
  --models gpt-5-2025-08-07
```
